# История изменений

Здесь фиксируются заметные изменения StackMIREA для пользователей, авторов материалов и разработчиков.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), а версии проекта следуют [семантическому версионированию](https://semver.org/lang/ru/). Журнал ведётся с 1 сентября 2026 года; более ранняя история доступна в [коммитах репозитория](https://github.com/minkinad/StackMIREA/commits/main/).

## Не выпущено

### Добавлено

- Глобальный полнотекстовый поиск с `⌘ K` / `Ctrl K`, клавиатурной навигацией, подсветкой совпадений и понятными empty states.
- Страницы «О проекте», «Архитектура» и «Помочь StackMIREA».
- Опциональные учебные метаданные, прогресс курса в браузере, стандарт образовательной страницы и MDX-компоненты для самопроверки, иллюстраций и сворачиваемого кода.
- Новый векторный логотип StackMIREA для README.
- `AGENTS.md` с инструкциями для кодовых агентов.
- Этот журнал изменений.

### Изменено

- Главная страница и каталог перестроены вокруг поиска и наполненных направлений; пустые дисциплины вынесены в блок «Скоро появятся».
- Страницы направлений получили roadmap, прогресс и структуру mini-course; статьи — метаданные, mobile TOC и навигацию только внутри своего курса.
- Обновлены репрезентативные материалы Java MVC, AI/KNN и Big Data по новому образовательному стандарту.
- Упрощены header, footer и представление команды; улучшены focus states, reduced motion и адаптивность контента.
- Светлая и тёмная темы сайта переведены с монохромной палитры на фиолетовую; обновлены фоновые градиенты, акценты, состояния фокуса и оформление документации.
- Фирменные SVG- и PNG-знаки приведены к новой фиолетовой палитре; социальное превью обновлено в формате 1200×630.
- README получил новую структуру, навигацию, badges, схему контентного pipeline и актуальные команды.
- Обновлены руководства для контрибьюторов, поддержки и безопасного сообщения об уязвимостях.
- Кодекс поведения и шаблоны GitHub приведены к единому русскоязычному стилю.
- В шаблонах pull request используются актуальные команды проверки проекта.

### Исправлено

- Исправлены пути статических ассетов и favicon для production `basePath` на GitHub Pages.
- Исправлен синтаксис YAML в шаблонах issues со значениями, содержащими двоеточие.

## Как вести журнал

- Добавляйте пользовательские и инфраструктурные изменения в раздел «Не выпущено» одновременно с кодом или документацией.
- Используйте категории «Добавлено», «Изменено», «Исправлено», «Удалено», «Безопасность» и «Устарело» только при наличии соответствующих изменений.
- При выпуске версии переименуйте раздел «Не выпущено» в `[X.Y.Z] — ГГГГ-ММ-ДД` и создайте новый пустой раздел сверху.
- Не включайте внутренние рефакторинги, форматирование и другие изменения, которые не влияют на пользователей или сопровождение проекта.
